# 왜 필요한가: 사전 원본(표준국어대사전 ∩ MIT 빈도목록)은 욕설만 걸러져 있고
# 성·범죄·자해·약물 관련 표제어는 그대로 남는다. 초등학생이 쓰는 서비스에서
# 실제로 제시어에 '흑인문제'·'생리대'가 노출된 것을 브라우저 실측으로 확인했다(2026-07-25).
#
# 규칙: 반드시 **정확일치**로만 거른다. 부분일치를 쓰면 설거지·별똥별·대변인·
# 유니섹스·새끼손가락 같은 멀쩡한 단어까지 사라진다.
#
# 사전을 재생성할 때는 scripts/filter-dictionary.mjs를 파이프라인 마지막 단계로
# 반드시 실행할 것. tests/dictionary-blocklist.test.ts가 누락을 잡는다.
#
# 형식: 한 줄에 한 단어. '#'로 시작하는 줄과 빈 줄은 무시된다.
